PolarUV APT Repository

This is the APT package repository for the PolarUV project. It hosts the packages required to run the PolarUV underwater robot.

Supported distributions

Ubuntu jammy Ubuntu noble Debian bookworm Debian trixie

Architectures: amd64, arm64.

Setup

Add the repository signing key and the APT source entry:

curl -fsSL https://apt.polaruv.tech/pubkey.asc \
  | sudo tee /etc/apt/trusted.gpg.d/polaruv.asc >/dev/null

echo "deb https://apt.polaruv.tech/ trixie main" \
  | sudo tee /etc/apt/sources.list.d/polaruv.list

sudo apt update

Replace trixie with your distribution codename (jammy, noble, bookworm, or trixie).

Install

sudo apt install polaruv

Repository layout

  • pool/ — package files
  • dists/ — APT metadata and signatures
  • pubkey.asc — repository signing key
